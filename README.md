# DAA Practicals

This repository contains Python implementations of Design and Analysis of Algorithms (DAA) practical experiments completed as part of the coursework.

## Overview

The programs in this repository demonstrate core algorithmic concepts such as:

- Searching and pattern matching
- Graph algorithms
- Divide and conquer
- Dynamic programming
- Backtracking
- Greedy techniques
- Sorting and performance comparison

## Experiments Included

1. Interpolation Search vs Binary Search
2. String Pattern Matching Algorithms
3. Minimum Spanning Tree (MST)
4. Dijkstra's Shortest Path Algorithm
5. Finding Minimum and Maximum Using Divide and Conquer
6. Matrix Chain Multiplication
7. N-Queens Problem
8. Travelling Salesman Problem (TSP)
9. Bin Packing Problem
10. Deterministic vs Randomized Quick Sort

## Repository Structure

- `exp1.py` to `exp10.py` – Individual practical implementations
- `README.md` – Project documentation

## How to Run

Each experiment is a standalone Python script. You can run any file using:

```bash
python exp1.py
```

Replace `exp1.py` with the desired experiment number.

## Requirements

- Python 3.x
- Standard Python library only

## Notes

These programs are intended for academic and learning purposes, especially for understanding algorithm behavior, time complexity, and comparison of different approaches.
